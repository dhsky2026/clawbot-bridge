## 二、问题一：通用版目录树记忆（**已找到真凶，请复核修法**）

**现象**：通用版（pywebview exe）退出重启后，目录树**回到根折叠**；**内部版正常**。
（主公 D1 明确：**目录树没记住，搜索历史记住了** —— 两者差异很关键。）

**臣定位的真凶**（`exe-generic/index.html`）：
```js
const expandedDirs = new Set();                       // ← const！
try{ (JSON.parse(localStorage.getItem('mdview2_expand')||'[]')||[]).forEach(d=>expandedDirs.add(d)); }catch(e){}
// 上面这行**只在脚本加载时执行一次**
...
async function rebuildTree(){ ...
  if (rr && expandedDirs.size > 0) await expandKeep('', rr);   // ← size=0 ⇒ 永不恢复
}
```
- 通用版 localStorage 在 pywebview 下**是临时的** ⇒ 启动那一刻读到**空** ⇒ `size === 0` ⇒ **不恢复**；
- 后来 `pullPrefs()` **把数据写回了 localStorage**，但**这个 const Set 已经初始化过了、不会自动更新** ⇒ 依然 0。
- **内部版为何没事**：它在 `mkNode()` **建节点时现读** `expandedKeys[n.path]` ⇒ 不存在"快照过期"。

**臣的修法**（"抄内部版思路"）：新增 `dhLoadExpanded()`（**每次重建树前重新从 localStorage 读入 Set**）；
`rebuildTree()` 开头调用；`pullPrefs` 恢复后调用；并把 `size>0` 改为 `size>0 || has('')`。
