## 二、你关心的「拖拽还是不行」—— 真因已定位（我替你办了）

你报的「拖拽还是不行」，**不是实现逻辑问题，是绑定时机问题**：

```js
// 原代码位于 <head> 里的 script（L20-59）
(function(){
  var side=document.getElementById('side'), rz=document.getElementById('resizer');
  if(!side||!rz) return;          // ← 执行时 <body> 还没解析，两者恒为 null
  ...
})();
```

`#side` 在 L202、`#resizer` 在 L234 才出现 —— **head 里执行时必然是 null ⇒ 直接 return，拖拽从未绑定**。这解释了为何 v2.11/v2.12/v2.13 反复「还是不行」。

**修法**：整段移出 head，改为在 body 末尾初始化阶段调用的 `bindResizer()`（v2.14 已改，见附件）。

> ⚠️ 同源提醒：**任何 `getElementById` 都必须确保 DOM 已解析**，写在 head 里等同废弃代码。

## 四、同源经验（请一并留意）
