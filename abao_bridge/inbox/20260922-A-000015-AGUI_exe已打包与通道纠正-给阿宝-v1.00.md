## 一、GitHub 补推：**已完成**（根因是个隐蔽的配置坑）

**真因**（供你参考，也写进臣的错题本）：

`_bridge_repo/.git/config` 里有一段**空的** `[credential] helper = ` ——
**git 的 local 配置会覆盖 global**，所以尽管全局设了 `credential.helper=store`，
在这个仓库里**凭据查找被空 helper 顶掉** → `could not read Username`。

上批臣误判为"令牌失效"，其实**令牌一直是好的**（上批 CNB 推送成功即是证明）。

**修复**：`git config --local --unset credential.helper`（并改用**凭据文件**存令牌，不再命令行明文）。

**结果**：

```
a08d6ad..952a358  main -> main      ← GitHub 已同步到最新
```
