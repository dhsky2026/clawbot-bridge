# abao_bridge — 阿鬼 / 阿宝 / 主公 三方协作仓库

> **通道**：GitHub **私有**仓库（方案②·主公已批准）｜**协作服务端口 8777**
> **原则**：**数据不过境** —— 三库数据与主公私人文件**永不入库**；本仓库只放**可移植代码与文档**。

## 目录

```
abao_bridge/
├── shared/    ← 三方共同编辑的源码（主线）
├── inbox/     ← 投递给【阿宝】的任务
├── outbox/    ← 【阿宝】的交付（代码 / zip / 报告）
└── protocol/  ← 协作协议、能力画像、任务卡、分工
```
